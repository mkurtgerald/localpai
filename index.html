What “strict local” means

The app does not persist generated photos to IndexedDB, Photos, Files, iCloud Drive, or a server. Once sealed, its service worker serves only already-cached resources and returns an error for every uncached request—even if Wi‑Fi and cellular remain on. The generator is disabled unless that seal is confirmed.

Reset / reinstall

Reset destroys all in-memory generated images and prompt text before reopening model downloads.

Airplane Mode is optional for app-level egress protection after the seal; it remains a useful independent verification test.
